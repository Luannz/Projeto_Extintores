Como funciona
  1. Na planilha, use uma linha por funcionário, com os títulos das colunas iguais aos campos abaixo.
  2. No modelo Word, escreva os campos entre chaves duplas, onde os dados devem aparecer.
  3. Envie os dois arquivos e clique em Gerar documentos.
